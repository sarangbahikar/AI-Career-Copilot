# AI Career Copilot 🚀

An AI-powered Resume Intelligence and Interview Preparation Platform.

## Features

- Resume PDF Upload
- Skill Extraction
- ATS Resume Scoring
- Resume Analysis
- Job Role Recommendations (Coming Soon)
- Interview Question Generation (Coming Soon)
- Personalized Learning Roadmap (Coming Soon)

## Tech Stack

- Python
- Streamlit
- PDFPlumber
- NLP
- GitHub

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
